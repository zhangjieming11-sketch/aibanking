# 部署说明 — AgentBank 智能体银行安全演示系统

> 本文件面向评审与复现者：说明如何从源码在本地运行、接入大模型、跑通测试。
> 仓库（可在线浏览）：**https://github.com/zhangjieming11-sketch/aibanking**
> 线上演示：**https://agent-bank-secure.app.workbuddy.host/**

---

## 一、环境要求

| 项 | 要求 |
|----|------|
| Node.js | **≥ 18**（用到了内置 `fetch`、`base64url`） |
| 第三方依赖 | **零依赖**，无需 `npm install` |
| 端口 | 默认 `3000`，可用 `PORT` 环境变量覆盖 |
| 操作系统 | Windows / macOS / Linux 均可 |

## 二、快速启动（本地，约 1 分钟）

```bash
# 1) 进入项目根目录（含 server.js 的那一层）
cd agent-bank

# 2) 直接启动（无需安装依赖）
node server.js

# 3) 浏览器打开
#    http://localhost:3000
```

## 三、接入大模型（可选）

**不配置也能跑**：系统自动降级为本地规则引擎，全部安全机制与功能正常，只是对口语化表达的理解弱一些。配置后体验更完整。

**方式一：配置文件**

```bash
cp data/llm-config.example.json data/llm-config.json
```

编辑 `data/llm-config.json`：

```json
{
  "baseURL": "https://你的接入点地址/compatible-mode/v1",
  "apiKey": "sk-你的完整Key",
  "model": "qwen-plus"
}
```

**方式二：环境变量**（推荐服务器部署，避免密钥落盘）

```bash
# Linux / macOS / Git Bash
export LLM_API_KEY=sk-你的完整Key
export LLM_BASE_URL=https://你的接入点地址/compatible-mode/v1
export LLM_MODEL=qwen-plus
```

```powershell
# Windows PowerShell
$env:LLM_API_KEY="sk-你的完整Key"
$env:LLM_BASE_URL="https://你的接入点地址/compatible-mode/v1"
$env:LLM_MODEL="qwen-plus"
```

> 环境变量优先级高于配置文件。任何 OpenAI 兼容协议（百炼 / DeepSeek / 通义 / Kimi 等）均可。
> ⚠️ `data/llm-config.json` 已在 `.gitignore` 中，**切勿把密钥提交进仓库**。

**验证**：登录后聊天页顶部徽标显示 `🧠 大模型：qwen-plus` 即接入成功；显示 `⚙️ 规则引擎模式` 表示未配置或调用失败。也可 `GET /api/agent/status` 查看。

## 五、数据与密钥（重要）

- `data/db.json`：**运行时数据**，删除后重启即恢复初始种子数据；**不入库、不随压缩包提供**。
- `data/llm-config.json`：**含真实密钥**，**不入库、不随压缩包提供**；请用 `.example.json` 自行生成。
- 因此第一次运行会**自动生成**演示数据，属正常现象。

## 六、线上演示与云端部署

- 线上演示：**https://agent-bank-secure.app.workbuddy.host/**（已部署最新版本）。
- 自行部署到任意支持 Node 的环境：设置 `PORT` 与 `LLM_*` 环境变量后执行 `node server.js` 即可；服务监听 `process.env.PORT || 3000`。

## 七、目录结构（关键文件）

```
server.js                    主服务（路由 / API / 静态文件）
lib/util.js                  密码哈希 / JWT / 参数 HMAC 签名 / 审计链哈希
lib/gateway.js               权限网关（安全核心：策略 / 授权单 / 审计哈希链）
lib/injection.js             数据隔离层：注入防火墙（唯一判定入口）
lib/agent.js                 意图解析 + 通道隔离 + 输出过滤 + 规则引擎兜底
lib/llm.js                   大模型接入层（OpenAI 兼容协议）
lib/banking.js               业务执行器 + 幂等 / 撤销 + 定时调度
public/                      前端（原生 JS 单页应用）
tests/                       测试用例与门禁脚本
docs/提交材料/               作品简介 / 技术方案 / 安全自评 / 演示脚本 / 答辩材料 / 本说明
data/llm-config.example.json 大模型配置模板（安全，可提供）
```

## 八、常见问题

| 现象 | 原因 / 解决 |
|------|-------------|
| 徽标显示「规则引擎模式」 | 未配置 / Key 写错 / 文件名不对；确认是 `data/llm-config.json` 并重启 |
| 请求 401 Invalid API-key | Key 与 baseURL 不配套（必须同一账号） |
| `EADDRINUSE` | 端口被占用，改用 `PORT=3001 node server.js` |
| 页面白屏 / 点不动 | 浏览器缓存旧版，`Ctrl + F5` 强制刷新 |
| 数据是空的 | `data/db.json` 不入库，首次运行自动生成，正常 |
