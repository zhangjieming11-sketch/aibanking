## 四、已知会翻车的点（提前规避）

| 现象 | 原因 | 处理 |
|---|---|---|
| 登录点不动 | 浏览器缓存了旧 `app.js`（旧版用内联 onclick，被 CSP 拦） | **Ctrl+F5 强刷** |
| 转账报「余额不足」 | 演示账号被前面测试消耗 | `POST /api/demo/reset` |
| 助手回「没听懂」 | 模型未配置，降级规则引擎 | 检查 `data/llm-config.json`；或直接用黄金轨迹页 |
| 短信验证码看不到 | 短信面板未展开 | 点右下角 📱 面板 |
| 页面样式全乱 | 演示模式 zoom 与浏览器缩放叠加 | 浏览器缩放调回 100% |
| 挂失后无法再演示 | 卡已冻结，不可逆 | 录完一段就 `reset` 一次，或分两遍录 |
